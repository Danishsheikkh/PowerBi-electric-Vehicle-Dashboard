# Washington State Electric Vehicle (EV) Population Analysis – Power BI

## Project Overview
This project analyzes the Electric Vehicle (EV) population in Washington State using Power BI. The dashboard provides insights into EV registrations, vehicle manufacturers, models, electric driving ranges, CAFV eligibility, and geographical distribution.

## Dataused 
<a href=" https://github.com/Danishsheikkh/PowerBi-electric-Vehicle-Dashboard/blob/main/Electric%20Vehicle%20Data.xlsx"><Dataset/a>

## Objectives
- Analyze the total number of registered electric vehicles.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Identify the most popular EV manufacturers and models.
- Explore EV adoption trends across different model years.
- Analyze EV distribution by county and city.
- Evaluate Clean Alternative Fuel Vehicle (CAFV) eligibility.
- Compare electric driving ranges across vehicle models.

## Tools & Technologies
- **Power BI** – Dashboard development and data visualization.
- **Microsoft Excel / CSV** – Dataset handling and preparation.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.

## Key Insights
The dashboard aims to identify electric vehicle adoption patterns, popular manufacturers, regional EV distribution, and differences between fully electric and plug-in hybrid vehicles.

## Dataset
The dataset contains vehicle registration information, including model year, make, model, EV type, electric range, CAFV eligibility, county, city, postal code, and vehicle location.

## Project Outcome
An interactive Power BI dashboard that transforms raw EV registration data into meaningful insights to better understand electric vehicle adoption across Washington State.
