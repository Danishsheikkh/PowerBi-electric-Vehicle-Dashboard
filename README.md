Washington State Electric Vehicle (EV) Population Analysis – Power BI

Project Overview

This project analyzes the Electric Vehicle (EV) population in Washington State using Power BI. The dashboard provides insights into EV registrations, vehicle manufacturers, models, electric driving ranges, CAFV eligibility, and geographical distribution.

Objectives

Analyze the total number of registered electric vehicles.

Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).

Identify the most popular EV manufacturers and models.

Explore EV adoption trends across different model years.

Analyze EV distribution by county and city.

Evaluate Clean Alternative Fuel Vehicle (CAFV) eligibility.

Compare electric driving ranges across vehicle models.
